## Projetos em destaque

### ⏱️ [Plataforma Jornada de Trabalho](https://github.com/Juliarezende521/Plataforma-Jornada-Trabalho)

Aplicação web para registro e gestão de jornada, com fluxos para colaborador, gestor e RH. Desenvolvida com **Angular, TypeScript, Java, Spring Boot e SQL Server**, inclui autenticação, controle de acesso, auditoria, ajustes de marcações, relatórios, testes automatizados e integração contínua.

### 🥋 Elite Fight Club

Projeto pessoal em desenvolvimento para gestão de academias de artes marciais, com experiências para alunos, professores e administradores.

- **[Backend](https://github.com/Juliarezende521/elite-fight-club-backend):** Java 21, Spring Boot, PostgreSQL, Spring Security, Firebase, Flyway e testes automatizados.
- **[Frontend](https://github.com/Juliarezende521/elite-fight-club-front):** React 19, TypeScript, TanStack Start, Tailwind CSS, Firebase e interface responsiva.

### 👥 [API REST de Clientes](https://github.com/Juliarezende521/API-Rest-Clientes)

API em Java 21, Spring Boot e PostgreSQL para gerenciamento de clientes, com validação, controle de e-mails duplicados, tratamento de erros, migrations Flyway, documentação OpenAPI/Swagger e testes automatizados.
